# 🐹 Хомяк-Инвест — симулятор биржи

## 📌 О проекте
**Хомяк-Инвест** — это бесплатный симулятор биржи, где вы торгуете криптовалютами и акциями на виртуальные деньги, но по реальным котировкам. Учитесь инвестировать без риска!

## 🚀 Демо
👉 [Открыть симулятор](https://[ваш-ник].github.io/homyak-invest/)

## 🎯 Возможности
- ✅ Реальные котировки криптовалют (CoinGecko)
- ✅ 6 криптовалют: BTC, ETH, TON, SOL, XRP, DOGE
- ✅ 6 акций: Сбер, Яндекс, Лукойл, Газпром, Озон, ВТБ
- ✅ Все комиссии и налоги как в жизни
- ✅ Рейтинговая система
- ✅ Сохранение прогресса в браузере

## 🛠️ Технологии
- HTML5
- CSS3 (адаптивный дизайн)
- JavaScript (Vanilla JS)
- CoinGecko API
- LocalStorage
